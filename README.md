# JavaScript Mini Projects
https://nishee05.github.io/Mini---JavaScript---Projects/

A collection of beginner-friendly JavaScript projects built using HTML, CSS, and JavaScript.

## 📂 Projects Included

### 🧮 Calculator
- Perform basic arithmetic operations.
- Technologies: HTML, CSS, JavaScript

### 🎲 Dice Game
- Simulates a dice roll with random number generation.
- Technologies: HTML, CSS, JavaScript

### ✅ To-Do List
- Add, delete, and manage tasks.
- Technologies: HTML, CSS, JavaScript

### 📝 Word Counter
- Counts words and characters entered by the user.
- Technologies: HTML, CSS, JavaScript

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ▶️ How to Run

1. Clone the repository.
2. Open any project folder.
3. Open the `index.html` file in your browser.
